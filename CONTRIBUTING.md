# Contributing to JUGNU 💜

Thank you for your interest in contributing to JUGNU!

JUGNU is a personal AI assistant project, and contributions are welcome to improve its features, usability, and performance.

## How to Contribute

1. Explore the repository and understand the existing code.
2. Check the Issues section for tasks or report a new issue.
3. Discuss major changes before starting work.
4. Fork the repository.
5. Create a new branch for your changes.
6. Make your changes and test them.
7. Submit a Pull Request with a clear explanation.

## Ideas for Contributions

- Improve the user interface and user experience.
- Add voice input and output.
- Improve chat history and chat search.
- Add support for selecting AI models.
- Improve error handling and performance.
- Update documentation and setup instructions.

## Code Guidelines

- Keep code simple and readable.
- Use meaningful variable and function names.
- Test your changes before submitting a Pull Request.
- Do not include API keys, passwords, or personal chat history.

## Questions?

If you have questions or ideas, open an Issue in the repository.

Thank you for helping make JUGNU better! 🤖
